## 页面规格

### 记忆（默认）

- 顶栏：标题 + 三轴 chip（写入状态 / 运行质量 / 新鲜度），不合并成单一颜色。
- 计数：`生效中 n · 当前项目 {name}`；`全部项目 n` 小字；无数据/不可用显示“未知”，不显示 0。
- 分段：生效中 / 本次会话 / 已停止 / 已过期 / 全部。**没有“待确认”分段**。
- 筛选：scope、kind、来源（自动/复盘/手动/迁移）、时间。
- 行：标题 + 摘要 + chips（scope/kind/来源/时间）+ 状态 + 行内动作。
- 详情：正文；来源链（session/message/project，review 显示逐字证据）；版本历史（按 `/api/items/:id/changes`）；关联（相似/覆盖/冲突）；动作（停止使用/撤销最近变更/历史版本恢复）；无法安全逆转时只给停止使用。
- 空态：`还没有生效记忆。自动写入开启后，符合条件的候选会直接出现在这里。`

### 活动

- 默认全部事件；顶部聚合：`今日 自动写入 n · 跳过 n · 失败 n · 撤销 n`，可点击筛选。
- 事件类型：自动写入/自动跳过/失败/撤销/恢复/停止使用/复盘/维护/迁移。
- 行：相对时间（title 绝对时间）· 类型 badge · 对象链接 · 原因（1 行可展开）· 结果（成功/失败/未知）· 动作（撤销/查看）。
- 失败/跳过必须显示原因类别（超时/限流/校验/重复/容量/敏感），不能只写“跳过”。
- **活动页不显示“待确认 n”**；legacy 审查只在 `#settings/advanced/review`，由用户主动进入。

### 设置

分组：写入与自动化（运行模式三选一，一次原子设置；展示 effective/blocked/reason/retryAt/lastSuccess；kill switch；服务端回退能力与保留天数）｜模型与阈值｜容量｜高级与维护（legacy 审查、健康、审计、图谱、技能、历史、备份）｜环境｜危险区（未实现的 erase 不显示假按钮）。

保留 `Settings.tsx` 的 revision/草稿/冲突保存协议；分组只改外层。

## 状态与动作语义

| 动作 | UI 文案/行为 |
|---|---|
| 停止使用 | 无确认弹窗；行内 loading；成功后行变“已停止使用 + 恢复使用”；`aria-live` 播报“已停止使用「标题」，下一次模型请求起不再注入（含旧会话）”；结果持久可见，不是 toast。**不得改分段、query、scope/type/source；动作前后恢复滚动位置**；详情若打开则保留并可恢复；焦点按 §视觉样稿裁决 第 2 条 |
| 恢复使用 | 回到原分段；活动新增恢复事件；清除抑制；**同样不改筛选与分段**，详情保留 |
| 撤销变更 | 版本化（`expectedVersion`）；冲突 409 → 显示“当前已被修改，无法安全撤销”，只给停止使用；**无“仅恢复文本”** |
| 版本回退 | 能力与窗口由服务端字段返回（默认 90 天）；仅在 `revertible=true` 时显示按钮；超期/冲突/不可回退不显示按钮，只保留停止使用并说明原因 |
| 运行模式 | 按 P03 契约一次选择原子设置 legacy/observe/autonomous 及相关字段；UI 只读 effective/blocked/reason/retryAt/lastSuccess；禁止“绿色开启但 shadow/observe 不写” |
| 撤销结果未知 | 复用 `undo-preview.ts`/Queue 的“结果未知”锁；不重复提交 |
| legacy 审查 | 设置›高级›review；活动页无 badge；不因规则/安全条目自动弹提醒 |

文案红线：

- 不写“只对新会话生效”；写“下一次模型请求起不再注入（含旧会话）”。
- 不承诺“已执行的外部动作/已开始的请求被撤回”。
- 不写“删除/清理”表达“停止使用”。
- 不写“全本地/云端已删除”；说明后台模型仍可能出网。
- 不把 confidence 写成“准确率/可信度”。
- 复盘失败不得写“已降级为模板合并”；写“本轮未形成复盘记忆，已有记忆与下次请求不受影响”，降级能力按子系统具体说明。

### 视觉样稿裁决（P05 必守）

1. 停止/恢复**不得改分段、query、scope/type/source**；动作前后恢复 `scrollY`；成功反馈持久（标题 + 恢复 + 查看活动），不用 toast。
2. 详情若打开必须保留并可恢复，即使条目已从 active 列表移出；焦点顺序：详情内动作 → 同位置下一行 → 顶部反馈条；rail 落到「最近操作」；聚焦用 `preventScroll`，不消失、不跳顶。
3. 计数三处分离：**分段总数 / 筛选后 N 条 / 全部项目**；未知显示“未知”不显示 0，不互相冒充。
4. 44px 不放宽：≤560 与 rail 所有可点 ≥44×44；rail 可调 260/320 密度，但基本动作不得靠 hover 才出现。
5. 运行模式按 P03 契约：一次选择原子设置 legacy/observe/autonomous + effective/blocked/reason/retryAt/lastSuccess；UI 只读服务端 effective，**禁止“模式已开但实际仍 shadow/observe 不写”**，不硬编码模型或状态。
6. 版本回退只信服务端可操作字段；过期/冲突/不可回退不显示按钮，只保留停止使用并写明原因。
7. 复盘失败 = 本轮未形成复盘记忆，不等于自动模板合并；不得混为一谈。
8. 验收必须分开记录「真实 360 视口」与「桌面画布中的 360 列」；补 rail 260/320、真机与移动 UA；不得用画布列冒充移动端通过。

## 依赖与稳定契约

- `GET /api/changes`：只读活动流，稳定供 UI；不返回 prompt/凭据/正文以外的敏感字段。
- `GET /api/memory/items`（新 envelope）：每行有 `version`/`changeID`/`source`/`revertible`；旧 `/api/items` 形状不变，UI 不自行推断版本。
- 三个 POST 都带 `expectedVersion`；冲突 409。
- 不依赖 `metrics.queue` 之类的聚合计数决定主路径；计数口径必须标注。
- 召回 `/api/recall` 只用于“相关记忆”面板/详情关联，不改变固定前缀。
