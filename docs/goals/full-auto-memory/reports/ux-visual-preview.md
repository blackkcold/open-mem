## 1. 这份样稿回答什么

P01 后端未交付前，用可点的静态样稿提前验证：

1. 视觉方向：暖灰纸面 + 墨绿，内容优先，不是通用 AI Dashboard 的卡片墙。
2. 主路径：记忆 / 活动 / 设置；普通自动记忆零待审；停止/恢复随处可发现。
3. 窄屏与扩展面：真实 360 视口、360 画布列、rail 260/320 是否还像同一个产品。

样稿只用于方向验收。视觉细节可在 P05 调整；语义边界（零普通审批、下一次请求失效、不做假删除、活动不催办）不可改。

## 2. 设计读取与方向

**Design read**：本地记忆控制台，给每天核对「系统到底记住了什么」的开发者；安静、可信、可追溯，偏账本式排版，不是营销页也不是监控大屏。

- 一行一条记忆，发丝线分隔，不用卡片；没有 KPI 方块、渐变、玻璃。
- 墨绿只用于主操作、当前选中、状态点。
- 数字与时间等宽；正文系统中文栈；不引入 webfont。
- 状态拆成三枚 chip（写入 / 质量 / 新鲜），不合并成一个颜色。
- 动效只做 120ms 透明度与边框，`prefers-reduced-motion` 直接停。

反模式自查：无 4 个彩色指标卡、无居中 hero、无 AI 紫、无 emoji 图标、无大面积阴影。

## 4. 三个页面

### 4.1 记忆（默认）

- 计数带口径：`7 条生效 · 当前项目 openmem-console · 全部项目 13`；工具栏单独写「筛选后 N 条」。
- 分段：生效中 / 本次会话 / 已停止 / 已过期 / 全部，**没有待确认**；每项 `title` 标注「共 N 条」。
- 搜索 + 范围/类型/来源筛选；输入只重绘列表，不动输入焦点。
- 行：标题 → 摘要（两行）→ scope/类型/来源/时间/版本；右侧状态与「停止使用」。
- 行内按钮默认 72% 不透明，hover/focus 满；不是隐藏。
- 详情：正文渐进展开（5 行折叠）、操作、来源、版本时间线、关联；无选择时给三行说明，不留空白惊吓。

### 4.2 活动

- 默认全部事件；聚合：`自动写入 5 · 跳过 2 · 失败 1 · 撤销 1`，中性可点筛选。
- 事件：时间、类型、对象、结果、原因；`查看版本差异` 展开 `−/+`。
- 失败/跳过写具体原因（超时、重复相似度、容量）；**复盘失败只写「本轮未形成复盘记忆，已有记忆与下次请求不受影响」，不再说「已降级为模板合并」**。
- 无「去确认」、无红色角标；legacy 审查只在设置。

### 4.3 设置（含 P03 模式契约）

- 一个「运行模式」三选一（旧版审查 / 影子观察 / 自动写入），原子设置相关字段。
- 下方独立「生效状态」行：显示 effective、阻断原因、重试时间、上次成功；**模式选择 ≠ 已生效**。
- kill switch「暂停所有写入」独立，优先于模式；开启后顶栏与设置同时变「已暂停 · 不写入」。
- 版本回退：「90 天，由服务端返回可回退字段；不可回退时不显示按钮」。
- 高级与维护：legacy 审查 0 条、健康、审计、图谱、技能、历史、备份；不催办。
- 不显示「删除副本」入口，并说明不承诺擦除备份与上游请求数据。

### 4.4 扩展 rail / 状态条

- rail 320/260：状态 → 最近写入（≤3，可停止）→ 最近操作（≤3，可恢复）→ 打开控制台。
- 操作后立即落到「最近操作」，不依赖 toast；260 下标题换行、按钮仍 44px、动作不隐藏。
- 状态条 88：写入状态 + 生效数 + 新鲜度，只读、无按钮、无催办数。

## 5. 交互裁决（本次修订重点）

### 5.1 停止/恢复不改用户上下文

- 停止后**不切换分段**（生效中仍是生效中），**不改** query、scope、kind、source。
- 不重置滚动：动作前后恢复 `scrollY`；列表因条目移出而缩短时不回到顶部。
- 成功反馈持久（非 toast）：带标题、`恢复使用`、`查看活动`、关闭；`position: sticky`，滚动时仍可见。
- 详情若已打开：**保持打开**，显示「已停止使用 + 恢复使用」，即使该条已从 active 列表移出；不因列表变化被清空。
- 恢复同样不切分段；从「已停止」恢复后该行离开当前列表，详情仍保留并可再次停止。
- 列表因停用变空时，空态改为「当前筛选下没有记忆 / 刚停用的条目已移到「已停止」，筛选条件保持不变」，并提供「查看已停止」。
- 计数：分段数字是各段总数，工具栏是「筛选后 N 条」，头部的「全部项目」是全局口径；三处不互相冒充。

### 5.2 焦点策略

| 场景 | 焦点落点 |
|---|---|
| 详情打开时停用/恢复 | 详情内的「恢复使用 / 停止使用」按钮（就地反馈） |
| 从列表停用，详情未开 | 同一位置的下一行（末尾则上一行）主按钮；不落到 body |
| 列表变空 | 顶部反馈条的「恢复使用 / 再次停止」 |
| rail | 「最近操作」里的恢复/停止按钮 |
| 滚动 | 焦点使用 `preventScroll`，不因聚焦跳动 |

### 5.3 版本能力由服务端给

- 详情只在 `revert.ok` 为真时显示「撤销最近变更」，并写明「可回退至 日期」。
- 不可回退时无按钮，写明原因：`90 天回退窗口已结束`、`存在后续编辑`、`由撤销产生`；只保留停止使用。
- 样稿用合成 `revert` 字段演示，不冒充真实 API。

### 5.4 复盘失败 ≠ 自动模板合并

- 复盘失败 = 本轮没有形成复盘记忆；不代表自动写入发生，也不代表自动走模板合并。
- 活动行显示「复盘未完成：模型超时（15s）。本轮未形成复盘记忆；已有记忆与下次请求不受影响。」
- 降级能力要具体（决策降级 / 重写降级 / 复盘失败各自后果），不把所有 degraded 都写成「模板合并」。

### 5.5 其他

- 搜索只更新列表与「筛选后 N 条」，保留输入焦点。
- 模式切换：影子/旧版时顶栏立即变「影子模式 · 不写入 / 旧版审查 · 不自动写」，不出现绿色「已开启」。
- 主题、表面（桌面/360 画布/rail）、rail 宽度 320/260 都是预览控制，不属于产品 UI。

## 9. 交给 P05 的约束

1. 停用/恢复不得改分段、query、scope/type/source；滚动保持；详情保持；焦点按 §5.2。
2. 计数口径三处分离：分段总数 / 筛选结果 / 全部项目；不可互相替代。
3. 44px 不放宽；rail 可调密度但基本动作不得靠 hover 才出现。
4. 验收必须分开记录「真实 360 视口」与「画布列」，并补 rail 260/320、真机与移动 UA。
5. 模式按 P03 契约一次性设置，UI 只读 effective/blocked/reason/retryAt/lastSuccess；不得出现绿色开启但实际 shadow/observe 不写。
6. 版本回退只信服务端可操作字段；过期/冲突不显示按钮，不放假入口。
7. 复盘失败文案不得声称自动模板合并；降级要写具体能力。
8. legacy 审查只在设置高级，无徽标、不催办。
